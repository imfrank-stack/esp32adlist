哈希表格式

每张表是排序去重的 uint32 小端数组（FNV-1a 32 位）。ESP32 存 Flash 二分查找，不占 RAM。

uint32_t fnv1a32(const char *s) {
    uint32_t h = 2166136261u;
    while (*s) { h ^= (uint8_t)*s++; h *= 16777619u; }
    return h;
}
// 查询：先查完整域名，再逐级去掉最左标签（后缀匹配）
