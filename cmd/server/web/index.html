快速开始

# 1. 看清单：选一个适合自己 Flash 的 profile
curl -s http://<你的服务器>:8080/api/v1/manifest | jq '.lists[] | {name,count,hash_bytes}'

# 2. 拉一页域名（文本，可直接写 hosts）
curl -s "http://<你的服务器>:8080/api/v1/lists/esp32-cn/domains?page=1"

# 3. 拉一页哈希（二进制，1024×4=4096 字节，适合 ESP32 分片存储）
curl -s "http://<你的服务器>:8080/api/v1/lists/esp32-cn/hashes?page=1" -o p1.bin

# 4. 按 Range 顺序流式下载整张表，边下边写 Flash
curl -s -H "Range: bytes=0-4095" http://<你的服务器>:8080/api/v1/lists/esp32-cn/raw.u32 -o chunk.bin

# 5. 查一个域名是否命中
curl -s "http://<你的服务器>:8080/api/v1/lookup/esp32-cn?domain=ads.example.com"

哈希表格式

每张表是 排序 + 去重 的 uint32 小端数组，每个元素是域名的 FNV-1a 32 位哈希。ESP32 只需二分查找，不需要存储任何字符串。

// 与固件完全一致
uint32_t fnv1a32(const char *s) {
    uint32_t h = 2166136261u;
    while (*s) { h ^= (uint8_t)*s++; h *= 16777619u; }
    return h;
}

// 查询：先查完整域名，再逐级去掉最左标签（后缀匹配）
// a.b.ads.example.com → b.ads.example.com → ads.example.com → example.com

32 位哈希在 30 万条规模下的碰撞概率约 1e-5 量级，且构建时已按值去重；碰撞只会导致极少数域名误拦，不影响正确性。
